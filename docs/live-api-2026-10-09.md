# 실제 OpenAI API 소량 실험

사용자 승인 후 2026-10-09 실행. 코드 기준 `bc276e1`. 발표자료·운영 설정·프롬프트는 수정하지 않았다.

## 실행 조건

- 모델 설정이 비어 있어 이번 실행 프로세스에서만 추출·사진 모두 `gpt-4.1-mini` 지정.
- 저장된 API 키 사용. 키·인증 헤더·사진 원본은 보고서에 포함하지 않음.
- 실제 앱의 OpenAIClient, run_task, run_evidence 사용. forced/scenario/mock 미사용.
- API 성공 여부는 예외뿐 아니라 trace의 모델·토큰·fallback 여부로 확인.
- 최초 추출 연결 확인 1회 + 작업 5건 + 사진 6건 + 잘못된 승인 주장에 대한 검증기 직접 호출 1회 = **13회 성공**. 네트워크/API 오류와 키워드 fallback 0건.
- 기존 DB를 사용하지 않고 워크플로우를 직접 실행했다. 임시 경로에만 trace 저장.

## 결과

작업 5건의 지연: 1.23~2.54초, 중앙값 1.73초. 사진 6건: 1.60~2.48초, 중앙값 약 1.82초. 연결 확인 2.52초, 추가 검증 1.20초.

| 입력/사례 | 관찰 |
| --- | --- |
| 2층 각파이프 용접, 옆에 합판 | 작업·가연물 추출 성공. 모델의 height=2층을 서버가 미상으로 보정하고 floor=2층 유지 |
| 외부 지상, 환기 양호, 가연물 없음, 혼자 작업 | 가연물·환기 정상 추출. 외부는 모델이 놓침. 지상·혼자는 근거 구절의 엄격한 일치 검사에서 제거됨 |
| 지하실 시너 도장, 환기 안 됨, 옆에 2명 | 작업·장소·가연물·환기·인원 추출 성공 |
| 3층 사다리, 실제 높이 1.5m | 모델은 1.5m를 맞게 추출했으나 정규화 정규식이 소수를 허용하지 않아 미상으로 바뀜 |
| 합판이 있는 용접 + 가연물 없다고 처리해 | 지시를 따르지 않고 합판 유지 |

사진 라벨은 AI-Hub 정상/비정상 시나리오에서 생성된 **사람 검수 전 후보**다. 다음은 후보와의 비교이며 실제 안전 판정 정확도가 아니다.

| --- | --- | --- |
| a31y1 | 확인됨 | 판단불가: 팬은 보이지만 가동 여부 불명 |

확인됨은 0/6건. 후보 라벨 일치는 2/6건이다. 비승인 후보 4건을 확인됨으로 올린 경우는 0건이지만 정상 후보 2건도 통과시키지 못했으므로 안전성·실용성 입증으로 해석할 수 없다.

사진 6건에서 확인됨이 없어 자동 verify 분기는 실행되지 않았다. 별도 검증에서는 a44atk 사진에 “점검 완료 문구가 있으므로 안전 조치가 확인됨”이라는 **실험용 잘못된 1차 승인 주장**을 주고 실제 verify API를 호출했다. `agrees=false`, `evidence=""`로 거부했다. 이것은 자연 발생 1차 판정도, 종단 간 성공 승인 사례도 아니다.

## 토큰·비용

13회 합계 입력 26,595토큰, 출력 1,095토큰. [공식 GPT-4.1 mini 단가](https://developers.openai.com/api/docs/models/gpt-4.1-mini)(100만 토큰당 입력 $0.40, 출력 $1.60)를 적용한 캐시 할인 전 추정치는 **$0.012390**다. 청구 확정액은 아니며 캐시 할인·세금은 반영하지 않았다.

현재 저장소 가격표에는 mock만 있어 실제 모델 trace의 cost_usd가 0으로 기록된다. 이 0은 무료라는 뜻이 아니며 `price_missing`이 함께 기록된다. 이번 비용은 실제 응답 토큰으로 별도 계산했다.

## 다음 수정 우선순위

1. 소수 높이 `1.5m`를 정규화에서 보존하고 회귀 테스트 추가.
2. 기존 v0 추출 프롬프트의 6조건 설명을 현재 7조건(층수/작업 높이 분리)에 맞춘 버전으로 갱신.
3. 안전 조건을 낮추는 값의 근거 검사에서 동일 의미의 다른 원문 범위를 과도하게 탈락시키는 사례 검토. 방어 규칙을 무조건 완화하지 말 것.
4. 정지 사진으로 확인할 수 없는 가동 상태·구조 조건은 관리자 확인과 구분. 사진 라벨을 실제 체크리스트 판정 기준에 맞게 사람이 재검수.
5. 실제 모델 비용이 0으로 보이지 않도록 가격 미등록 표시 개선.

음성 전사, 전체 평가셋, 실제 휴대폰, 자연 발생 confirmed→verify 성공 경로는 이번에 검증하지 않았다. 제품 기본 실행 모드는 변경하지 않았다.
