# 안전반장

건설 현장 반장을 위한 안전 점검·사진 증빙 모바일 웹앱을 만드는 프로젝트입니다. 안전 안내는 법률 자문이 아닌 참고용입니다.

현재 저장소에는 Python 개발 환경과 모바일 웹 화면 틀이 구현되어 있습니다. 시작 화면과 탭 이동을 확인할 수 있으며, 작업 입력·사진 판정·점수 계산을 처리하는 서버 기능은 아직 구현되지 않았습니다.

## 현재 구현된 것

| 범위 | 내용 |
| --- | --- |
| 개발 환경 | Python 3.12, uv 설정과 의존성 잠금, pytest |
| 협업 설정 | Codex 작업 규칙, PR 템플릿, CODEOWNERS, 환경·데이터·빌드 제외 설정 |
| 웹 설정 | Vite·React·Konsta·Tailwind, PWA manifest와 서비스 워커 빌드 |
| 공통 UI | 색·글꼴 토큰, 상태 배지, 버튼, 칩, 카드, 사진 표시, 빈 화면, 스켈레톤 |
| 시작 화면 | 시작하기 버튼, 방문 여부 저장, 저장소 접근 실패 처리 |
| 화면 이동 | 작업·할 일·사진·기록·평가 탭, 체크리스트·작업자 확인 경로 |
| API 호출 준비 | JSON 요청, FormData 전송, HTTP 오류 처리 래퍼 |

시작 화면을 제외한 일곱 화면은 **준비 중**으로 표시됩니다. API 래퍼는 구현되어 있지만 연결할 백엔드 서버는 아직 없습니다. 화면 상수만 있으며 가짜 평가 수치는 표시하지 않습니다.

## 실행 방법

Python 3.12와 uv, Node.js 20.19 이상의 20 계열 또는 22.12 이상, npm이 필요합니다.

저장소 루트에서 테스트에 사용할 Python 환경을 준비합니다.

```bash
uv sync
```

웹 개발 서버를 실행합니다.

```bash
cd web
npm install
npm run dev
```

터미널에 표시되는 주소로 접속합니다. 기본 주소는 `http://localhost:5173`입니다. 개발 서버는 외부 접속을 허용하도록 설정되어 있어 같은 Wi-Fi의 휴대폰에서는 터미널의 Network 주소로 접속할 수 있습니다. 화면 확인 기준은 390×844입니다.

처음 접속하면 시작 화면이 나옵니다. **시작하기 →**를 누르면 작업 화면과 하단 탭이 표시됩니다.

| 주소 | 화면 |
| --- | --- |
| `/#/` | 오늘 작업 |
| `/#/todo` | 반장 할 일 |
| `/#/evidence` | 증빙 사진 |
| `/#/ranking` | 기록 |
| `/#/eval` | 평가 |
| `/#/checklist` | 체크리스트 |
| `/#/worker/1` | 작업자 확인 화면 틀. 시작 화면과 하단 탭을 표시하지 않음 |

현재 개발 서버의 `/api` 요청은 `http://localhost:8000`으로 전달하도록 설정되어 있습니다. 서버 실행 명령은 백엔드 구현 후 추가합니다.

## 검증

저장소 루트에서 실행합니다. API 래퍼 테스트는 Node.js로 실행하며 실제 서버나 LLM을 호출하지 않습니다.

```bash
uv run python -c "import fastapi, uvicorn, httpx; print('ok')"
uv run pytest -q
```

웹 빌드는 다음과 같습니다. 결과물은 `web/dist/`에 생성됩니다.

```bash
cd web
npm install
npm run build
```

2026-10-09 확인 결과:

- Python 의존성 import: `ok`
- pytest: `2 passed`
- 웹 빌드: 성공, PWA 서비스 워커 생성
- 390×844 Chrome 확인: 시작 화면, 탭 5개 이동, 56px 돌출 사진 버튼, 작업자 경로의 시작 화면·탭바 제외, localStorage 접근 차단 시 동작 확인. 페이지 오류 0건

휴대폰 실기기 확인은 아직 수행하지 않았습니다.

## 화면과 작업 규칙
